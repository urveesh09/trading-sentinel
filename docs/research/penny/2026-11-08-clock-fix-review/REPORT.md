## Additional fixes
1. **Cash release does not restore evidence completeness.** NO_EVIDENCE expires only hypothetical unobserved entry intents and frees conditional paper reservations so collection continues. It remains in the denominator and each row records that capital assumption. A later closed trade cannot make complete_modeled_net available again while any decision is missing. capital_path_complete is false, and closed_modeled_net_subtotal remains explicitly partial. This is a continued paper experiment conditional on excluding the missing intent, not a reconstructed continuous real account. Real modeled OPEN positions continue to hold cash and slots.
2. **Consistent volume clocks.** Positive volume delta with a last trade at/before the decision is no evidence; a later trade with unchanged volume is also inconsistent. Neither becomes measured zero capacity or a fill. Consistent unchanged volume with no later trade retains the inherited zero-observed-capacity refusal.
3. **Published auction matching clock.** An older 09:10 matching packet can be accepted at 09:12; an unverified 09:08 trade stamp is not treated as a confirmed match under the current published 09:10–09:12 schedule. The earlier proposed test accepting 09:08 as a match was corrected. If the provider reports a different convention, archive/verify that mapping first.
4. **Smart source qualification.** PENNY_SMART_AUCTION_ENTRIES_ENABLED defaults false. The pre-open observer and legacy reference books remain. A changed LTP alone does not prove an indicative auction price. The API retains its prior change indicator, adds indicative_price_verified=false and entry_enabled, and does not create new forward Smart entry intents by default. Synthetic funded-entry tests explicitly opt into the price-source assumption. The code does not invent another failed preselected-limit strategy or buy after the auction at its earlier price.
5. **Idle recovery.** A scheduled idle morning phase expires missed matching observations before returning, without a quote request. This avoids leaving expired PENDING rows until the following day.

The existing independent sibling store requires no schema migration. Older UNRESOLVED rows use the inherited NO_EVIDENCE behavior, with incomplete capital history explicit. No real position is erased. The corrected synthetic exercise accepts an output path so old result artifacts are retained.

## Remaining work

Existing LTP equality on two days establishes the observed limitation, not a universal theorem about all future packets. Overnight needs actual 15:51 and end-of-session receipts, followed by matching observations with verified provider clock semantics. Queue priority, partial fills and own executions remain unknown.
