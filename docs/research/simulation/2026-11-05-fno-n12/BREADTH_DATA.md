# NIFTY constituent participation input

Obtain the official Nifty50 Equal Weight close series. It uses the same constituent universe as NIFTY 50 with equal weights at review, so its relative price return is a measure of how a different weighting of the same companies moved. It does not identify advance-decline counts, signed order flow or the direction of tomorrow's market. [NSE Indices methodology](https://www.niftyindices.com/indices/equity/strategy-indices/nifty50-equal-weight), [official NSE history](https://www.nseindia.com/reports-indices-historical-index-data).

Use the fixed January 2021 to November 4, 2026 date contract, quarterly public requests and the existing close validation. Store the normalized series and raw responses locally. Bind their hashes and matched-session availability against the already sealed official NIFTY close series. Do not read, train on or score a strategy in this acquisition slice. In a later directional comparison, require the preceding common official close and test the relative return against a cap-weight-only benchmark before assigning option prices. No broker request, settings, runtime or Production change. Rollback is to retire the research input.
